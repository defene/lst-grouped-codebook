# LST 非线性颜色表示：接入与首次检查

2026-09-27。已实现 `C_power`、`C_asinh`，与已有线性灰度 `G`、线性颜色路径 `C` 共用模型、物理域污染和温度评估接口。本次仅执行 CPU 合成数值检查，没有读取 HLP 图像、初始化模型或启动训练。

## 定义与来源

给定每张图的均值 μ，以 r=T−μ 为输入。均值协议仍由实验配置决定，各模型必须一致；本映射不自行估计均值，也不逐图调整尺度。预测后逆变换并加回同一个 μ。

统一范围 A=120°C，固定尺度 τ=2.6950881812941048°C，来自 HLP v2 218,975 条训练记录的残差标准差。证据为 `runs/paper1/lst_residual_scale_20260918/residual_scale.json`；未用 val/test 选择尺度。

把 r 映射到 s∈[−1,1]：

- 线性颜色 C：s=r/A。
- 幂变换颜色 C_power：令 g(r)=sign(r)·[1−(1+|r|/τ)^(−2)]，s=g(r)/g(A)。
- asinh 颜色 C_asinh：s=asinh(r/τ)/asinh(A/τ)。

再令 u=(s+1)/2，沿等长度的七段 RGB 路径插值：黑→红→黄→绿→青→蓝→品红→白。模型张量映射至 [−1,1]。解码先找最近线段，再逆非线性映射；路径外 RGB 的最近投影可能存在分支切换，不是任意三维 RGB 与温度之间的双射。超出 ±A 的颜色输入报错，不静默截断。

借鉴来源是 [Vision Banana / Image Generators are Generalist Vision Learners §3.2](https://arxiv.org/html/2604.20329v1#S3.SS2) 中的非负深度幂变换与分段颜色编码。**这里的有符号扩展、有限范围归一化和训练集尺度是 LST 适配，不是原论文原公式复现。asinh 是独立对照。** 将标量编码为 RGB 不意味着其分布已经等同于自然图像。

## 实际执行的检查

每个区间等距取 100,001 个合成标量，检查 FP32 往返误差；在五个内部点核对解析局部 Jacobian 与自动微分、往返梯度，并检查超范围拒绝。全部通过。技术门槛为 FP32 最大绝对误差≤0.05°C，不是模型性能目标。

|表示|±10°C 范围 FP32 RMSE|±120°C 范围 FP32 最大误差|
|---|---:|---:|
|G 线性灰度|0.000000152°C|0.00000763°C|
|C 线性颜色路径|0.00000815°C|0.0000229°C|
|C_power 幂变换颜色|0.00000516°C|0.02453°C|
|C_asinh 非线性颜色|0.00000217°C|0.0001526°C|

另做了一个假设 RGB 被量化成 8 bit/通道的敏感性检查。实际训练表示保留浮点，不经过此量化。

|表示|±10°C 均匀标量的量化后 RMSE|±120°C 均匀标量的量化后 RMSE|
|---|---:|---:|
|G|0.27019°C|0.27169°C|
|C|0.03884°C|0.03881°C|
|C_power|0.01926°C|13.51978°C|
|C_asinh|0.00925°C|0.10068°C|

幂变换更集中地表达零附近温差，代价是大温差处颜色扰动被显著放大；asinh 也有尺度分配取舍。以上均匀标量不代表真实 LST 残差分布，8 bit 误差也不等于神经网络预测误差，不能据此排名 VAE 或宣称复原性能提升。

机器记录见 [mapping_checks.json](../../../runs/paper1/lst_colour_mapping_check_20260927/mapping_checks.json)，包含源码与尺度文件摘要。复现命令：


表示比较和实验顺序以 [最终设计](FINAL_PLAN_V2_ZH.md) 为准：VQ八种表示、SD七种三通道表示，首先在pixel10训练条件下归因；增加非线性匹配灰度与仿射增益控制，避免把标量放缩收益混同于颜色路径收益。

现有 `default_config` 支持C_power/C_asinh，但匹配的G_power/G_asinh尚待接入。主比较RGB辅助损失规定为0；现有代码的局部Jacobian补偿能力不是本轮额外实验条件，不能直接沿用其非零默认系数。共同物理损失下的逆映射梯度、错误分段和饱和死区须在P0检查。

以上合成映射结果保留为数学检查证据，不代表模型复原性能或真实图像分布匹配。所有训练入口仍关闭，实际配置和模型运行有待验收。
