# A05：HLP v2 五轮温度实验

用户于2026-09-15授权启动刚约定的实验。范围为最近的四组温度对照：原始预测、原始预测＋空间4倍、残差预测、残差预测＋空间4倍。沿用卷积VQ-VAE、1024码字、680个多尺度索引和模型规模；本轮不包含HLS或Prithvi。

全部从零训练，seed17。显式读取 `processed_data/hlp_split_v2_20260914`，使用剩余train归一化，三份split-local QA形状库也按v2重建并验证来源。训练218,975条，val11,684条，test11,757条，成员和tile两两隔离。

每组5个完整epoch：有效batch64＝微批4×累积16，每轮3422次更新，最后一次31条；总17110次更新、1094875次记录呈现（每条1个训练视图）。按实际样本数加权梯度，不跨epoch补齐、不丢弃或重复尾批。各组使用相同的EpochSampler顺序与缺失生成规则。学习率1e-4，前500次更新预热，随后余弦衰减至1e-5。其他优化参数与A04相同。

正式比较固定最后一轮last.pt，避免最佳epoch不同造成预算不一致。每轮完整val的约10%缺失条件监测，不用test调参、不提前停止；所有四组训练完成后，再在完整val/test上分别测干净和约10%缺失输入，每条两个实现。保留每轮epoch检查点与对应指标。test曾被历史实验查看，本轮不会抹除这个事实；新的val独立于本轮从零训练。

空间4倍＝原MSE＋额外3倍逐图去均值空间MSE，VQ系数保持一致。残差预测＝从可见输入估计逐图温度均值，以它为基准学习图内空间残差并加回，不读取目标均值。每幅图辅助基准32bit计入码率。

四组先通过技术检查：67条train、8条val/test、2个epoch，尾更新3条；先训练2步存盘，再恢复至4步，校验训练流、精确epoch、独立v2归一化、推理、显存。技术检查的权重不用于正式训练。正式两组GPU作业并行，每进程分配上限12GiB；整卡剩余低于2GiB时请求存盘停止。报告单作业共享GPU墙钟时长，并按活动区间并集统计总GPU-hours，不能简单相加。

入口：`python -m experiments.paper1.lst_v2_5epoch.prepare` 后 `python -m experiments.paper1.lst_v2_5epoch.supervise`。输出 `runs/paper1/lst_v2_5epoch_20260915`。根目录STOP文件停止队列，各作业STOP文件停止相应训练；恢复时须先核验停止原因、旧进程、冻结源代码和配置。训练核心data.py/train.py/run.py/mask_bank.py、原eo_denoise/eo_data与旧残差模型代码在开跑后冻结；日志、调度和报告允许在不改变实验定义的前提下修复。

最终中文报告需对比总体/均值/空间/梯度误差、缺失区/保留区、码字分布，并结合预测图谨慎解释细节恢复。不把短程A04或旧v1模型直接当作等训练预算对照。
