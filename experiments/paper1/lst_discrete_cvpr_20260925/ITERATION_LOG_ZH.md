# 本轮设计审查与修订记录

2026-09-25；仅文献核验、已有文件只读审计、方案编写、配置算术校验和交互说明视图检查。没有模型前向/反向、短程训练、评估或新权重下载。

| 审查问题 | 已落实的设计修订 | 仍需未来执行核验 |
|---|---|---|
| 仅K对齐，VAR680token和FSQ单尺度不等载荷 | 核心固定16×16、四量化机制；VAR另列 | 真正索引/bitstream |
| FSQ推荐配置不一定等于目标K | 主表exact-K；1000状态推荐levels敏感性单列 | levels配置行为 |
| A120绝大多数图仅一条颜色边 | 不宣称丰富颜色；增益仿射控制、色域独立决策 | train像素段占比及可训练范围 |
| 缺失填0而mask通道不一致 | 共同输入mask/mean适配及decoder μ条件 | 实测适配参数和输入审计 |
| RGB零输出不等于零温差 | scratch物理初态校准，pretrained保持原始头 | 初值/曲线分支/梯度 |
| 零颜色头可能无法跨段学习 | 共同局部Jacobian归一化表示辅助项＋4个关辅助对照 | C跨段可达性阻断检查 |
| 绝对温度控制公式不完整 | 独立field合同，同A、train中心、无固定μ加回 | train中心冻结及条件公平性 |
| clip与loss顺序歧义 | raw inverse→training loss→eval投影 | C内部clamp仍需单独记录 |
| 前置gate出现未解析ID | 改为已登记gate，静态断言所有引用可解析 | 实际gate均未通过 |
| encoded input不能跨R/G/C同hash | 物理/目标/mask、mean、representation分层校验 | 运行时实现 |
| 旧test长期被查看、HLC有交集 | 历史探索与外部确认明确分开 | 独立成员和footprint证据 |
| 名称和投稿要求被过度承诺 | 去除未实施cross-view/真实去噪/新SOTA表述 | 结果决定贡献范围 |

静态最终清单：140个训练设计格（72核心＋68支持），6个零微调状态，592个完整模型状态×split×condition单元。每val11684、test11757；两个视图不重复计独立记录。

验证脚本通过的是配置与预算算术、状态空间、载荷、ID、对照关系和执行禁用，不是模型实现质量。交互说明已在浏览器核对：完整范围显示140格/2395400更新，12bit模式显示4096状态、3104bit含均温标称载荷，排版与联动可用。
