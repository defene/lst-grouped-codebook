# 有限离散载荷下的温度场表示：LST 完整实验方案

版本：2026-09-25 / 设计 v2。**本轮不训练、不测速、不下载权重、不评估模型。** 本文件是新实验的设计，不修改历史冻结实验。

## 1. 先把论文问题说清楚

目标不是证明“某个 VAE 的 RMSE 最低”，也不是预设“卫星图像变成彩色就更好”。我们要研究：图间平均温度变化远大于图内变化时，有限数量的离散符号能否有效表示局部温差；不同量化机制、残差化及数值表示各起什么作用？

主推对象是**物理场的离散 tokenizer**，不绑定可学习 VQ 码本。FSQ、LFQ、BSQ 都可以成为最终方法的组成部分。编码仍只能使用当时可见的温度、已知均温与有效性信息，解码结果统一回到摄氏度。

当前可提交的工作定位应先写作“给定均温的 LST 离散重建与缺失恢复研究”。只换颜色、换量化器、增加对照，并不自动形成 CVPR 方法贡献。完整方案必须允许否定颜色假设、否定某种量化器优势，甚至得出仍缺少新方法贡献的结论。

暂不沿用 **Cross-View Discrete Tokenization for Noise-Robust Earth Observation** 作为已成立的方法标题：本轮没有跨模态训练机制，两个评估 mask 不构成 cross-view 学习，随机缺失也不等于真实传感器噪声去除。

## 3. 数据、任务与信息边界

数据为 **HLS-LST-Pairs（HLP）**，不是 Prithvi 团队发布或生成的数据。输入为单幅 fine LST，256×256；本轮不用 HLS 引导，不是 coarse→fine 超分辨率。参考是卫星反演产品，不称无误差地面真值。

```python
ds = open_dataset('prithvi', 'lst', split,
                  prepared='processed_data/hlp_split_v2_20260914')
T = ds.denormalize(sample['image']) / 100.0
R = sample['reference_mask']
```

train/val/test 分别为 218975 / 11684 / 11757 对，2796 / 147 / 151 tiles。不得重新随机划分。当前仅证明 record/tile ID 无交集，未证明 footprint 完全不重叠。只在原本有效的 R 内人工遮盖，天然无效区没有重建准确性的标签。

主条件：μ=mean(T[R])；r=T−μ。μ 在人工遮盖之前计算，作为所有方法共享的**完整参考均温侧信息**。输入残差只保留可见位置，输出 T_hat=μ+r_hat。不把参考温度或参考纹理送入模型；主评分不把可见输入覆盖回输出，不用完整真值做预测后纠偏。

这是一项有 oracle 条件的任务，任务内公平不等于现实中一定可获得 μ。每幅图 μ 计32bit，必须实际以 float32 序列化并用相同值中心化和加回；不能计算时用 float64、码率却称仅32bit。完整 μ 的计算可用 float64 归约后转换。其他已知支持信息另行计费。

均温机制对照包含两种不同问题：

1. **直接绝对温度控制**：同样可获得 μ，将其送入公共输入和decoder均值条件分支，但预测 x=T−c_train（c_train是只由train拟合的固定总体中心），输出 c_train+x_hat，不使用逐图μ加回捷径。与残差组共用A和表示F，缺失x填0。这是同可用信息下的输出参数化比较，包含固定捷径与优化初态差异，不能称只改变一个数值平移。scratch绝对组初始输出c_train，残差组初始输出μ；差别必须如实记录。
2. **可见均温部署版本**：μ_vis 只由可见输入计算，训练/推理都如此。这是条件改变，不当作相同任务的纯表示消融。

推理压力测试 μ+δ 时，输入中心化、μ驱动decoder条件和输出加回均使用同一个扰动均值；另报冻结全部网络计算及decoder条件、仅最终addback加δ的解析平移敏感性，不能混淆两种实验。直接绝对温度控制没有addback，该解析诊断不适用。

## 4. 比较分四条轨道

| 轨道 | 控制什么 | 可以回答 | 不能回答 |

| A 量化机制 | 同骨干、同位置数、同标称bit、同物理目标、同初始化规则 | VQ/FSQ/LFQ/BSQ的离散化差异 | 完整官方大模型排名 |
| B 表示机制 | 同量化器比较R/G/C及增益控制；同骨干连续AE | 收益来自均值、幅度、通道、颜色路径还是量化 | 颜色改善必然来自接近自然图像分布 |

| D MAE空间补全 | 同一整块缺失，真实token dropping机制 | 块状缺失恢复 | 随机像素主榜或相同压缩率 |

## 5. 核心量化器：4种机制，1套空间骨干

共同骨干优先沿用已使用的 VAR 卷积残差编码器/解码器模块，初始结构候选 ch128、每级3个残差块、ch_mult=(1,1,2,2,4)，输出16×16位置。共享中间接口32通道；不加入重建不使用的参数。

| 机制 | 主配置 | 内部维度/状态 | 固有项 |
|---|---|---|---|
| VQ | K1024，D32，单尺度 | 学习1024×32码本 | codebook + commitment；更新规则单独冻结 |
| FSQ | levels=[8,8,16] | 3维，乘积1024 | 有界标量、round STE；不套VQ码本损失 |
| LFQ | 10 binary dimensions | 1024种状态 | sign量化、commitment与原生entropy适配 |
| BSQ | 10 binary spherical dimensions | 1024种状态 | L2球面归一化、缩放二值向量和原生entropy适配 |

FSQ exact-K 方案是本研究的同状态数控制，不是论文推荐默认；其推荐 `[8,5,5,5]` 实际1000状态，可同为10bit/token，另做敏感性对照。FSQ没有学习码本，不意味着任何LST训练都保证全状态使用。LFQ/BSQ的10维亦为我们的同率适配，不能称完整复现MAGVIT-v2或BSQ原生tokenizer。

各量化器必要投影不同，但输出均投影回32维供同一decoder使用。报告骨干、投影、量化器各自参数和总量，不用无用参数凑等参数。不同内部维度是机制的一部分，不能强迫FSQ使用32个量化轴。

主空间组织固定256个token×10bit=2560bit，加μ为**2592bit/图**；不含mask、容器和共享权重。这是 token 标称载荷。旧 VAR 多尺度 `[1,2,3,4,5,6,8,10,13,16]` 共680索引，加μ为6832bit，必须另列。

### 不能把弱VQ当靶子

基础VQ保持可复现的gradient codebook更新，不给部分表示组私加重置。再用预先固定的EMA/unused-code恢复版本比较R/C，检查结论是否只针对一个脆弱训练配方。每种方法有相同的train/val调试预算上限；不能只调主推方法的超参数。

FSQ1000、EMA-VQ、RQ/多尺度、近期Leech量化是不同轴，不合并成“最新VQ”标签。RQ和分组VQ并不等价：前者逐层量化残差，后者分解通道或子空间。

## 6. 表示设计：先消除混淆，再检验颜色

主表示保持用户指定的线性标量归一化：z=r/A，保守参考 A=120°C。R=z；G=(z,z,z)；C=2g((z+1)/2)−1。g为RGB立方体七条边的分段线性路径：黑→红→黄→绿→青→蓝→品红→白，线段等参数长度。R/C为两条主路线，G控制通道复制。

这是一维值的可逆冗余编码，不增加观测信息；“线性归一化＋分段线性RGB”不能简写成整体全局线性映射，也不能据此声称自然图像分布已经匹配。

**现有证据揭示了弱点。** train残差标准差为2.6950881812941048°C，A120使90.7373%图像的全部有效残差落在同一中央线段。在此段 C=(-1,1,7r/A)，因此C/G差异还包含7倍局部增益和偏置。当前C只能作为无截断参考，不足以证明丰富颜色的机制。

为此增加 **C_affine=(-1,1,7r/A)** 的全域仿射控制：它在中央段与C完全相同，域外允许数值越界，不能称自然图像RGB。逆变换用第三通道，其余两通道不产生温度信息。它用于判断折线路径是否超出局部增益作用；按预先定义的中央段/尾部分层同时报告，不从test挑有利子集。

### 色域问题必须显式决策

本版不静默把A改成小范围，也不逐图min-max。A120参考保留，无截断往返需要读取实际完整数据范围确认。更有检验力的颜色方案作为独立后续分支：

- 小A裁剪：仍线性缩放，但不可逆；R/G/C同样裁剪，先给出表示自身的温度误差下限、尾部覆盖，不称无损映射。
- train拟合非均匀路径参数：可保持全物理范围可逆，但实质改变标量增益；必须配相同一维warp的灰度对照，不再声称纯线性路线。
- 每图额外幅度：改变当前“只给均值”的条件，必须统一给予各模型并计侧信息，不能由某组独享。

这些分支不纳入当前固定作业清单。选择只基于train映射诊断与预先限定的val试验，需产生新的表示版本；不能凭test模型分数挑A。若坚持纯线性、有限RGB、全范围不截断三条件，弱图内色差是需要接受的约束，不是靠更换命名能消除的。

### 输出范围与优化公平性

主评分所有模型都使用相同的物理投影 `clip(T_hat,-50,70)`（源产品已筛选的域；以完整数据审计为前提），并同时保存投影前预测。C逆变换额外含RGB曲线投影，应单独记录分支选择、投影距离和饱和比例。R/G也先遵守相同残差定义域约束，再做共同温度投影。投影原始/约束后的分数均记录，主表列名明确；不能仅给颜色模型裁剪。

计算顺序明确为：表示输出→raw_readout→训练物理损失→仅评价的残差域投影→共同温度域投影。R/G的raw_readout不clip；C最近段逆映射内部不可避免包含线段clamp，因此不能声称C训练无硬边界。其端点死区和非相邻分支切换必须先做解析和有限差分验收。

为让颜色模型能离开初始化中央线段，本版建议所有表示共同加入物理单位归一化的表示辅助项（第10节），不只给C救助项。同时列入辅助项关闭的对照，避免把不同目标的收益冒称纯数据预处理。若仍无法跨段学习，则C对应作业保持不可执行，独立改为可学习物理读出头或新表示版本后重新审查；不能把结构性不可训练当算法负结果。

scratch残差模型统一校准为零残差初始预测：颜色的零残差输出是(-1,1,0)，不是(0,0,0)。后者经最近线段并列选首段可能解为约−102.857°C。共享中间权重不等于相同物理初态；末层的零权重和各自物理偏置规则必须记录。但仅零头＋物理逆解损失可能让前两颜色通道永远没有跨段梯度，所以物理初态校准不是可训练性证明。绝对温度组按上文初始化为c_train。预训练模型保留原始头，不能清零破坏预训练后仍称原权重零微调。

## 7. 掩码和条件必须真的对齐

R为天然有效mask，M为人工missing且M⊆R，O=R\M。像素10%在R内无放回抽 round(0.1|R|)，缺失值先填r=0后映射，禁止先在不同颜色通道分别遮盖。

主卷积及预训练微调模型都使用同一类型的轻量输入适配器：将表示值、R、O以及均值条件平面输入1×1层，输出原接口通道数；初始化为值通道恒等、mask及均值权重零，随后共同训练。μ条件采用train固定尺度，不由完整真值空间图构成。即便残差模型不需要μ，适配器也允许获得它，以对齐绝对温度控制的信息。

这样保留官方RGB编码器主体，同时避免旧VQ拼mask、旧SD只填0的信息不对称。各组decoder第一层特征还使用同类型的μ条件仿射支路（零初始化的μ驱动gain/bias，原特征恒等），使直接绝对温度组也能从规定侧信息解码，而不是被迫重新把μ塞进索引。新增参数实测列出。解码器不接未编码的可见温度、不做U-Net式像素跳连；唯一物理量旁路为规定的μ。R可用于有效支持/评价，M不作为免费传给codec解码器的温度重建通道。

预训练零微调状态保留恒等适配器，mask和μ支路为零，不宣称已经学会使用它们；这是迁移起点，不是与微调模型相同的训练状态。

随机数由 split、record ID、epoch、view、mask seed 确定，与模型/量化器/训练seed无关。样本顺序在同一seed比较中一致；不同训练seed可以改变初始化/训练顺序，评估mask始终相同。

## 9. MAE 专门方案

256×256、patch16产生256patch，无放回选26，即10.15625%名义覆盖。所有模型使用同一个外部缺失patch集合，另报有效支持上的实际遮盖比例，不再次随机mask。

Prithvi采用单帧空间MAE，编码只看可见tokens，插入mask tokens后按原位置解码；不传时间地理条件。SatMAE++保留其多尺度重建机制。两者若缩小参数是结构适配版本，不冒称官方大模型权重。

原生MAE masked-only监督与VQ全图监督不是相同训练目标；该表比较完整补全方法。clean对应同结构AE控制，不能称0遮盖原生MAE预训练。禁用需要被遮盖patch真实均值/方差才能恢复温度的patch目标标准化。

主补全指标是缺失区RMSE和跨缺失边界梯度误差；全图、保留区也报告。另可生成所有方法一致的“保留观测、只填缺失”成品图，评分单列，不替代完整codec重建分数。

## 10. 损失、调试与预算

物理共同尺度s=2.6950881812941048°C，来自当前train残差统计，与表示输入范围A不同。拟采用：

`L_phys = mean_valid(((T_hat_raw-T)/s)^2) + 0.1 * mean_valid_edges((gradient(T_hat_raw-T)/s)^2)`。

拟定共同表示辅助项 `L_repr = mean_valid(sum_channels((y_hat-F(x))^2) * A^2/(k*s^2))`，k对R/G/C/C_affine分别为1/3/49/49。梯度与通道归约必须照公式执行，不能再额外除通道数。该归一化来自每段表示导数平方范数，局部可与摄氏度误差对齐；跨颜色分支时并非全局等价的物理距离，不能声称完全相同优化几何。

主总损失建议 `L_phys + 0.01*L_repr + L_algorithm`；0.01是冻结前待验的共同候选，不是已经调优结果。它给颜色法向及跨段纠错提供梯度，非原生MAE的R/G/C模型包括连续对照都同样使用；Prithvi/SatMAE++保留独立轨道原生监督，辅助权重为0。新增4个VQ/FSQ R/C对照将此权重设0，其余不变；若无辅助C陷入死区，要报告优化失败，不据此主张颜色有/无信息优势。绝对组x=T−c_train，oracle/visible组x=T−各自μ，最终均在相同T域监督。

边仅在两个端点都有有效参考时监督，horizontal/vertical按有效边总数归约。像素mask只改变输入；主重建目标覆盖全部天然有效像素，missing/observed单列诊断。原生量化正则按各方法适配，不给FSQ强加VQ损失，不给BSQ凭名称加commitment。暂不加GAN或RGB LPIPS主目标，避免生成细节等同于真实温度结构。

连续KL模型按元素平均KL，预设候选1e−6，正式冻结前核验posterior/API/缩放；没有codebook perplexity。训练sample、评价mode，官方FLUX开关需实测。原生目标的改动全部公开，不写“完全复现官方训练”。

起始优化建议：AdamW，weight_decay .01，warmup500后cosine，clip1；scratch lr1e−4，预训练微调lr1e−5。这些是拟定值，不是已证最优。每方法限定相同数量的train/val候选试验和相同短程预算，只用val，搜索成本单列。冻结选定参数后，各表示组共用同一量化器配方，不能分别为颜色组多调参。

正式5epoch、有效batch64，每epoch3422更新，尾批31，17110更新/模型，1094875次呈现。尾部按实际样本加权累积，不能drop或补齐，也不跨epoch凑批。固定第五轮末为主checkpoint，保留学习曲线；五轮只能主张等数据预算性能，不等于充分收敛。长程收敛对照若追加，应同组共同增加预算并单列。

## 11. 主指标、统计与判据

**主任务终点**：clean完整重建RMSE；pixel10人工缺失区RMSE。缺失图的完整RMSE、observed RMSE必须同时显示。空间/梯度是必要伴随指标，不能总体RMSE改善但细节消失却称全面更好。

逐图 e=T_hat−T，bias=mean_R(e)，spatial_RMSE=sqrt(mean_R((e−bias)^2))。逐图有 MSE=bias²+spatial_MSE；跨图需明确宏/微加权，不能随意平方平均RMSE。主表使用像素加权 pooled RMSE，另报逐图与等tile宏平均。有效像素数/边数/缺失数同时保存。

补充：温度MAE、P95/P99误差、梯度RMSE、空间方差保持比、异常高/低温区域误差；阈值仅从train确定，平坦图方差近零不做不稳定比值。SSIM使用固定物理动态范围，不以逐图minmax掩盖幅值误差。FID/自然RGB LPIPS不作为LST主物理指标。

量化诊断：联合索引使用率/entropy/perplexity、每图token熵、相邻重复率、最细尺度/各层分别统计；FSQ边际熵之和不当联合熵，空状态不一定是训练失败。token一致性只在同一个模型的不同缺失视图间比较，不在不同码本间直接比较ID；常数token很稳定，必须与细节保真同时解释。

所有主配对预先冻结：每量化器 C−R、C−G；每表示 FSQ−VQ、LFQ−VQ、BSQ−VQ；clean训练与pixel10训练分别分析，不挑最优训练条件后混写。主要结论以VQ/FSQ的C−R和FSQ−VQ为预定主要contrast，其余为支持或探索；多比较如报告显著性用Holm校正并列出完整contrast族。

seed17/23/42的均值、标准差及逐seed结果全部报告。按tile聚类的配对bootstrap2000次针对测试抽样不确定性；训练seed变异另报，不能把2视图或3seed×像素当海量独立样本。主差值方向预设为负更好，95%区间跨0则报告不确定；不临时发明有利显著性阈值或只报赢的seed。

## 12. 率失真、mask成本与非神经对照

固定16×16位置，8/10/12bit分别使用VQ/LFQ/BSQ的256/1024/4096状态；FSQ exact-K levels为[8,8,4]、[8,8,16]、[8,8,8,8]。8bit的4levels违反原论文每维至少5的经验建议，因此要明示配置敏感性，不能用该单点代表FSQ整个能力。

每图表列：名义token bits、μ32bit、mask/头部、实际打包字节、如实现熵编码则真实码流字节；固定长与entropy下界不同。只有完整encode/decode roundtrip并统计文件开销后，才谈实际压缩比。主对照不将连续float latent算成等比特率。实际压缩若作为论文主贡献，必须再加入适用于标量场的标准压缩/变换编码对照；目前主线是离散token表示，不提前宣称最佳压缩器。

R的天然有效支持bitmap是评价和文件解释所需信息，最坏可超过token载荷；应分别给“共享支持条件下token载荷”和“自包含码流”账本。随机mask由生成seed可复现只适用于合成测试，不能把真实任意缺失mask也当免费。

无训练必要基线：μ常数图；masked输入直接保留/缺失填μ；固定邻域插值和调和填充（只读可见值）；clean低分辨率8×8/16×16重建、相同bit预算的量化块均值或DCT系数。后两类必须传系数且算bits；缺失条件不能从完整参考先降采样再假装恢复。额外给表示encode→decode的误差下限。

## 13. 泛化、鲁棒性与真正的token用途

不新增训练即可规划测试曲线：随机缺失0/5/10/20/40%，固定patch缺失；主表pixel10，其余为分布外压力测试。所有mask由同一可复现规则派生。δμ∈{−2,−1,−0.5,0,0.5,1,2}°C的敏感性公开；不根据压力测试反调主参数。

若要扩展“噪声鲁棒”主张，另立加性/结构噪声训练与评估协议，给出物理依据和幅度；当前不能把插值缺失恢复描述成真实传感器去噪。没有天然缺失的干净标签时仅定性展示。

**外部确认是重要缺口。** 现有test已被反复用于历史研究观察，只能诚实称既定基准，不能恢复为从未接触的blind test。HLP/HLC有1767相同tile ID，HLC不是自动独立外部测试。候选确认集需排除与HLP全体历史训练/验证/测试重叠的位置、场景/日期或近重复，核验单位、网格、质量和许可；不足以证明独立时换独立来源，不能自行重划分旧数据洗成新test。

从HLP训练直接在符合条件的HLC fine-LST上测试叫跨域评估；在HLC重新训练后测试叫第二数据集复现。两者分开，未知样本数不虚填。HLS六波段残差扩展待LST机制冻结后另立版本，按波段均值、谱角/光谱指数及一个共享离散载荷重新设计，不简单复制六份模型。

若论文主张token对后续建模有用，补一个**冻结tokenizer后的token预测任务**：固定预算的小型masked token predictor从可见编码预测目标token，与相同输入、容量和预算的连续latent预测器比较，并在最终物理域评分。干净目标token只作监督、推理不可见；mask造成encoder感受野泄漏必须审计。仅重建好不能声称语义token或生成建模更好。该下游属于需另行实现/冻结的论文扩展，不在140个自编码器格中。

## 14. 论文证据与反证安排

| 要说明的事情 | 必须出现的材料 | 不能省略的反证 |
|---|---|---|
| 离散载荷用于局部差异 | 量化主表、3点率失真、图内token/温差关系 | 常数均温、连续AE、低复杂度图层 |
| 颜色超出增益作用 | R/G/C/C_affine、同物理初态/边界、roundtrip | 若C_affine同样好，应归因增益而非丰富颜色 |
| 均值旁路有帮助 | 同信息绝对温度、完整/可见均值对照 | μ可获取性和误差敏感性 |
| 性能不是弱VQ产物 | FSQ推荐levels、EMA/restart VQ、搜索成本 | 量化器原生机制与适配差异 |
| 模型具备泛化能力 | 冻结终测、外部确认、质量/方差分层 | 历史test曝光、地理重复和参考产品误差 |

主图固定为：问题与条件示意；率失真(总体及空间)；表示×量化交互；mask与μ敏感性；横向预测/误差/缺失对比；token空间图及失败例。图像样例由record hash与train固定方差阈值规则选择，包含完整有效图与低中高空间变化，所有模型同例同温度范围、误差范围。看完所有图再写视觉复核记录。

若颜色无益，保留并报告，主线可收束到均值条件下的量化与码率分配；若现代量化器也没有可靠优势，不能把普通VQ应用包装成新算法。若发现优化/增益解释全部收益，应写通用物理表示机制而不是离散专属贡献。若只有LST单一已观察数据结果，不能扩大到普遍EO基础表示。

## 15. 成本、复现与交付门槛

每次正式结果需数据/归一化/mask/配置/代码/权重hash，精确呈现与更新计数、逐图预测充分统计、token打包定义、映射状态、参数/FLOPs/峰值显存、正常/中断会话和评估时长。中断后未存盘重算计入成本，不计为额外独立训练预算；共享卡并行小时不能直接相加当物理单卡GPU-hours。

主结果发布前必须核验每完整val单元11684、test11757、每条件两视图但独立记录不翻倍。跨模型共享的是相同任务条件下的physical_observation_hash、target_hash、mask_hash；mean_hash只在相同均值条件下相等，representation_input_hash只在相同表示与均值条件下相等，R/G/C编码张量本来不同。检查点只能来自本数据版本和预算。第五轮末结果与任何最佳val结果分栏。保存失败和中止记录。
