## 2. 研究对象与贡献边界

建议研究问题：在图内动态范围较小、图间均值变化较大的 LST 物理场中，什么表示与量化设计能在有限离散载荷下保留局部变化，并改善缺失观测的恢复？

- 主线是离散表示；VQ 与 FSQ 是量化机制，颜色编码是有待验证的输入/输出表示假设。
- 已知完整图均温是用户指定的条件任务。它可以保持为主实验，但不能等同于部署时已知缺失区域温度。
- 连续 AE、自然图像预训练 KL-VAE 和地球空间 MAE 确定性能边界。它们不自动构成同码率、同训练目标或同初始化的对照。
- 重建误差更低，不直接证明离散 token 更适合生成、跨模态预测或下游识别；这些结论需要独立任务证据。
- 不把“将已有颜色映射、VQ、FSQ 串起来”预先写成新算法。必须说明针对什么失败机制提出了什么设计，并通过反证控制验证。

## 3. 主张—证据—反证标准

| 候选主张 | 必须提供的控制和证据 | 什么结果会削弱或推翻主张 |
|---|---|---|
| 残差化有利于紧凑离散表示 | 同骨干、同量化器、同预算比较绝对温度与均温条件残差；均温侧信息明确计入或单列 | 优势仅来自免费真值均温，或消除输出整体偏移后空间误差没有改善，则只能称任务简化 |
| 颜色路径有超出简单增益的价值 | R 单通道、G 灰度复制、C 颜色；必要的增益匹配仿射 RGB 控制；共同物理监督与明确输出域 | 仿射载体同样有效，或优势来自更大输入增益、投影裁剪、不同损失尺度，则不能归因颜色几何 |
| 改善与离散化机制有关 | 同骨干连续 AE、VQ、FSQ 的表示交互比较；报告离散/连续容量差异 | 所有 AE 都近似同幅改善，说明是一般表示预处理；不能称解决了离散量化特有问题 |
| FSQ/VQ 在给定载荷下更适合物理场 | 相同 token 数或相同标称位预算的比较，多个预先固定载荷点，真实参数/吞吐/显存统计 | 只在某一个配置有优势，或收益由更多 token/更多位数解释，则不能宣称整体效率优越 |
| 局部空间结构得到保留 | 去均值空间误差、梯度误差、方差保持率、按空间变化程度分层的结果和固定视觉案例 | 只有总体 RMSE 下降，梯度/空间误差变差或图内输出更平滑，不能称细节改善 |
| 缺失恢复更稳定 | clean/pixel10 训练交叉评价；多个预先确定的测试缺失率；missing/observed 分区；空间插值基线 | 仅保留区误差改善，缺失区无增益；或仅在训练同分布 mask 上有效，则应缩小鲁棒性结论 |
| 改善可泛化 | 未参与设计的外部确认数据；固定模型、预处理和选择规则；单位、分辨率、参考产品审计 | 在 HLP 内有收益但外部消失，应报告适用域；不能用重新训练的结果冒称直接迁移 |

主比较在协议冻结前确定。可把空间重建和缺失区重建分别设为 clean 与 pixel10 的主要指标；全图 RMSE、梯度与保留区误差作为共同报告项。不得在看过 test 后更换主要指标来掩盖失败。

## 4. 需要优先解决的混淆因素

### 4.1 颜色映射与范围

当前旧版 LST 设计指出，A=120°C 时 90.7373% 的训练图片所有有效残差都落在候选颜色路径中央同一线段。这个统计来自旧版训练缓存审计，并不是本轮新实验结果。因此该映射主要检验仿射颜色载体，无法充分检验多段颜色编码的优势。

冻结前必须选择并记录范围和尾部策略，只用训练统计及允许的验证预算决策。若范围变小，应对所有表示明确裁剪或越界处理，并报告仅表示往返引入的物理误差。若使用每图自适应幅度，必须说明幅度由哪些可见信息求得，并计入其侧信息；不能只记录均温成本。

一维物理值可逆映射到 RGB 不增加新信息。可能的收益来自冗余、优化条件或网络归纳偏置。G 控制可以排查通道数效应，但不能完全排除颜色曲线斜率引入的增益效应；应保留增益匹配仿射控制。颜色输出投影到曲线带来的约束也需明确，不得只对一类表示实施有利裁剪再比较。

### 4.2 已知均温与 mask 接口

完整有效区域均温 μ 对所有模型同样提供，可以支持条件任务内公平性，但不能证明实际缺失场景可获得 μ。主要结果应标明“给定完整均温”；另用固定主模型检验可见像素均温、均温误差及其对重建的影响。必须说明输入中心与解码加回的均值是否相同，不能暗中使用不同信息。

缺失残差填 0 与真实均温像素不可区分。协议必须明确：是否提供显式缺失 mask、如何注入每类模型、适配器初始化和参数量，以及天然无效 mask 的处理。所有模型的 mask 来源相同，不等于模型获得的信息相同。MAE token mask、天然无效区域与人工 missing 应分开记录。

### 4.3 初始化、损失、预算与容量

同骨干替换连续瓶颈/VQ/FSQ 属于机制实验，应尽量固定所有共同部分。自然预训练 VAE、原生 MAE 属于完整系统比较，必须公开预训练、适配、损失和 latent 容量差异。

五个完整 epoch 是等数据呈现预算，不保证各模型收敛；应报告学习曲线，必要时将收敛诊断列为独立预算而不改变主表。学习率、损失权重和适配器选择也属于搜索预算，不应只给主推方法更多调参机会。

等参数和等离散载荷是不同问题。FSQ 没有学习型 VQ 的同构码本参数，不能添加无用参数“补齐”。连续模型的浮点 latent、MAE 可见 token、VQ/FSQ 的索引也不能只按元素个数称为同压缩率。

## 5. 数据隔离与独立确认

沿用项目冻结 HLP v2 划分；不得为了结果重新随机切分，也不能把历史模型见过的旧训练池中新 val 成员称为独立验证。

当前 test 曾被多轮历史实验查看。这不自动使其失去作为固定基准的意义，但研究过程已从这些结果获得信息，不能再宣称其完全未影响研究选择。应如实把历史分析标为探索阶段，冻结新的主张、选择规则和实验清单，然后统一终测；同时争取未用于方案选择的独立外部确认集。

tile ID 不相交只能证明 tile-disjoint。需进一步审计 footprint 重叠、邻接裁片和同地点不同日期；未完成前不得宣称空间 footprint 零重叠或严格地理外推。发现问题时另建明确版本，保留原划分及历史结果，不静默替换。

HLC 可作为候选外部证据，但必须先确认目标单位、参考产品、空间分辨率、成员独立性及均温定义兼容。HLP 训练模型固定后直接评估，才是直接迁移；在 HLC 重新训练后评估属于第二数据集复现。外部数据一旦用于选方法，应降为开发数据并另找确认来源。

统计上，重复日期/同 tile 图像并非独立样本。图像配对差值之外，建议按 tile 聚类构造区间；多个 mask 视图也不是新增独立地理样本。训练 seed 间波动与测试集抽样区间须分开报告。关键结论建议多 seed，但具体数量是项目预算决策，而非 CVPR 强制规则。

## 6. 去噪、跨视图与下游结论的使用条件

- 随机遮掉 10% 有效像素，直接支持“随机像素缺失恢复”。patch 缺失支持另一类空间补全，须另列条件。
- 人工缺失没有验证传感器测量噪声恢复。若使用更一般的“噪声鲁棒”标题，需增加定义明确、有物理依据的噪声协议；真实去噪主张还需要可信参考或专门的真实噪声评估设计。
- fine LST 是卫星反演参考产品，不等于无误差绝对真值。天然无效区域没有监督参考，不能用目测声称恢复正确。
- “Cross-View”需要实际跨视图机制，例如同源不同扰动的表示一致性或跨观测学习，并有移除该机制的消融。仅对一个模型生成两套评估 mask，不构成 cross-view 方法。
- 若声称 token 可支持生成或下游任务，应固定相应下游训练协议，比较相同下游模型和预算，并避免把 tokenizer 的重建结果当下游效用证据。

## 7. 离散表示与压缩的账目

当前可报告 token 数 × 每 token 标称位数，加明确的均温/幅度等侧信息。此值应称标称载荷；困惑度和经验熵不能直接当成实际文件码率。

若压缩是主要论文贡献，需要实现可复现 bitstream 编码和解码，计入索引、均温/幅度、mask、头部及熵编码开销；公开共享模型是否排除及其摊销方式。FSQ 应报告各维 levels、状态数乘积、索引编码及未用状态处理。连续 VAE 只有指定量化与序列化后才能进入实际码率对比。

推荐至少分开报告：标称离散载荷、实际编码文件大小（若已实现）、模型存储、编码/解码耗时、峰值显存。空间插值使用完整可见观测，属于恢复能力基线，不能直接充当低码率压缩方法。

## 8. 论文所需的最小证据组织

1. 主结果表：核心离散方法、表示、训练遮盖条件，明确参数、token 载荷、均温条件和共同物理指标。
2. 机制消融表：绝对温度/残差、R/G/C/仿射控制、连续 AE/VQ/FSQ，逐项对应第 3 节主张。
3. 载荷—误差曲线：预先固定若干离散载荷点，同时看全图、空间和梯度误差，避免单点排名。
4. 缺失鲁棒曲线与独立 MAE 表：随机像素与 patch 条件分开，展示 missing/observed 区域及非学习插值基线。
5. 独立确认表：冻结后的外部直接迁移或第二数据集复现，准确命名其泛化范围。
6. 固定视觉案例和失败例：统一物理色标、误差色标、选择规则，展示低/中/高空间变化与完全有效样例。
7. 统计与成本附录：配对差值、tile 区间、seed 变化、搜索预算、完整计数与输入指纹；训练作业小时与单卡区间并集分开，中断重算不隐藏。

核心证据应能在正文中成立。补充材料承担配置、完整分层结果和复现细节，不能把所有关键反证或失败情况藏到附件。

## 9. 新颖性风险及结果不成立时的收束

| 观察到的结果 | 合理收束 | 不应继续使用的表述 |
|---|---|---|
| 颜色收益由增益匹配或投影解释 | 研究重点转为物理场归一化、约束与优化条件，完整报告反证 | 新颜色空间天然提高信息容量 |
| FSQ 比 VQ 稳定，但无新的设计机制 | 作为离散化选择和有价值基准结论；寻找可复现失效规律 | 将直接替换标准 FSQ 声称为新的量化算法 |
| 连续 AE 同样获益 | 将表示方法定位为一般自编码预处理，离散部分作为应用 | 离散瓶颈专属突破 |
| 给定完整均温有效，可见均温下失效 | 保持明确的条件编码任务，报告依赖和应用边界 | 真实缺失条件下无额外信息的普适恢复 |
| 只在当前 HLP 或当前 K 有效 | 缩小适用范围，报告外部与载荷失败例；可形成诊断或基准贡献 | 通用遥感离散表示或全面效率优势 |
| 重建细节好，但真实 bitstream 未实现 | 定位紧凑离散表征，报告标称载荷 | 已验证实际压缩率优于现有压缩器 |
| 跨视图或真实噪声机制没有实现 | 使用重建/缺失恢复的准确标题 | Cross-View / real-world denoising 的已验证主张 |

若仅得到已知方法的组合和单数据集增益，方案仍可提供有用的内部证据，但不足以预先认定方法新颖性。可以进一步形成有明确发现的系统性诊断、可复现评测基准，或提出由失败机制驱动且经过控制实验支持的新设计。最终论文贡献应由结果决定，而非为了维持最初标题而扩大解释。

## 10. 审查通过的含义

本文件中的设计门槛通过，仅表示实验更可解释、可复现，不代表方法一定有效或论文一定获录用。正式执行仍需用户后续授权及新方案自身的实现/数据检查；本轮明确不启动训练、预处理或评估。
