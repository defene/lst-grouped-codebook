# A04 历史模型完整补测

用户于 2026-09-14 明确选择先补测现有四组 2,000 步 LST 模型。本任务不启动新的 5 epoch 训练。

- 模型：原始预测、原始预测加空间损失、残差预测、残差预测加空间损失。均固定使用 `lst_residual_20260913/pilot` 下的 `last.pt`，不根据补测结果选择检查点。
- HLP v2 完整 val 11,684 对、test 11,757 对；读取显式指定 `processed_data/hlp_split_v2_20260914`，不随机重划分、不使用历史 256 条上限。
- 干净输入与约 10% 已知掩码缺失，各两个实现；共 16 个评估单元、187,528 次记录评估和 375,056 次前向预测。所有模型收到相同的输入字节流，按集合和条件校验 SHA256。
- QA 缺失形状按新 val/test 各自抽取，严格校验源索引、样本索引、形状成员、文件哈希。它只是合成缺失几何，不是实际成对云污染数据。test 的噪声种子含 test 标记，区别于历史旧 val 标记。
- 数据和指标使用 v2 剩余 train 的归一化。UnitAdapter 在模型边界进行固定仿射单位换算：v2→旧模型输入单位→旧模型输出→v2。不可向模型传入参考目标或目标均值；无效及合成缺失输入在转换后仍严格置零。旧统计仅作为冻结模型兼容参数，不能用于今后新训练。
- 启动时验证冻结模型源代码、原训练数据指纹、2,000 步和原训练样本流。旧模型实际训练过新 val 的 6,563 条记录，val 是历史模型复查，不能解释为独立验证。test 未进入这些训练流，但有历史监测和试验决策暴露，不能称为未查看测试集。
- 主 RMSE：有效像素内 MSE→每条记录平均两个实现→记录等权平均→开平方。另报均值/空间/梯度误差、缺失区和保留区误差、码字使用与困惑度。码字困惑度不能单独证明空间细节改善。
- 每个单元保存逐条指标、完整成员、输入摘要、模型与数据哈希。失败可重新运行相同命令，校验并跳过已完整提交的单元；未完成的单元重跑，不覆盖原模型。`STOP` 文件请求在批间停止。
