# prithvi_data 可控加噪实验草案

日期：2026-09-09。用户提出将这批基本无噪声的数据作为参考，在其上人工构造噪声。下列噪声类型、强度和训练比例是实验建议，尚未生成全量加噪数据，也未开始训练。

## 目标与数据单位

以原始可靠影像 X 为固定参考，构造输入 X_noisy = C(X; type, severity, seed)，学习从污染输入恢复同分辨率影像。所有噪声施加在编码器之前；隐藏或污染的原始值仅用于监督，不泄漏给输入分支。

本数据的样本键为 `(split, tile, obs_idx, row, col)`，不能沿用另一份月序列数据的 `(sequence_id, month)` loader。HLS 是 `[6,256,256]`，LST 是 `[256,256]`。沿用现有 train/val 的 tile 划分。单模态加噪恢复的输入与目标来自同一个数组，不依赖 HLS 与 LST 严格同期。跨模态辅助作为单独实验，保留时间和空间匹配条件。

“干净”在此指作为合成实验参考的原始观测，不声称绝对无测量误差。已有 nodata 和明确无效像元不作为监督真值；缺失编码需先识别，不能在除尺度或加噪后再猜测。

## 先以云形缺失为主，数值噪声作补充

| 类型 | 构造 | 建议初始强度 | 实验解释 |
|---|---|---|---|
| 云形/阴影形状缺失 | 在可靠区域覆盖不规则 mask，归一化后填 0，提供输入可用 mask | 有效参考区域的 5%、10%、20%；25%、50% 为压力测试 | 有参考的缺失区域恢复 |
| 薄云或雾的合成扰动 | 光学波段使用空间变化的透射率混合，单独定义波段系数和云层颜色 | 校准参数后冻结；暂不指定物理强度 | 简化合成污染，不直接代表真实云形成过程 |
| 云影的合成扰动 | 光学波段局部乘性衰减，保留柔和边缘 | 例如衰减系数 0.8、0.6、0.4，属于待验证设置 | 简化合成阴影，与完全缺失分表 |
| 加性噪声 | X_noisy = X + sigma * epsilon | 固定训练集尺度上的若干 sigma，先做 pilot 选择范围 | 数值鲁棒性补充 |
| 条带、坏点与局部偏置 | 按行/列相关偏移或稀疏异常点构造 | 分别控制幅度、条带宽度和比例 | 结构化传感器噪声补充 |

现有研究计划以云、影和缺失恢复为主要问题。因此主表首先采用云形缺失协议；是否增加数值噪声主实验，以用户后续选择为准。不要只用独立像素 Gaussian 噪声代表所有遥感退化。

优先从 train 的原始 Fmask 提取云、阴影连通形状，保留类别、来源样本、形状 hash 和尺寸。val 的形状库独立，不回流训练。不足以达到目标覆盖率时记录真实达到的覆盖率；若使用程序生成的不规则形状，单独标记为程序合成，不称为真实云形状。

HLS 六波段共享遮挡几何，但数值扰动可同时包含跨波段相关分量和独立分量。LST 独立定义自己的噪声模型；不要直接套用光学“加白/变暗”的系数。将 HLS 的某个云形状用于 LST 时，它仅是合成几何模板，不代表该时刻 LST 的真实云位置。

## 输入、参考与评价 mask

分别维护：

- M_ref：原始参考可用于监督的区域。
- M_corrupt：本次人工施加污染的区域。
- M_in：输入实际可用性，缺失型实验中为 M_ref AND NOT M_corrupt。

只在 M_ref 内构造本次受控污染。缺失型实验使用已知 M_in；加性噪声、薄云或阴影实验中，像元仍有观测值，不能一律把它们标成缺失。是否提供真实污染位置必须作为明示的实验条件，所有对照一致。

主要评价区域为 M_ref AND M_corrupt；同时评价 M_ref AND NOT M_corrupt 的保持性。被人工遮住的位置有原始参考，必须进入损失和评估；已有真实无参考孔洞不进入定量分母。空区域不参与该项损失，避免除零。

## 建议的最小实验顺序

1. HLS-only 和 LST-only 分别建立可靠自重建与合成缺失恢复基线。
2. 固定容量、码率、训练预算和噪声 realization，对比连续 AE、基础 VQ、VQ 加稳定性约束；FSQ 可作为量化方式对照。
3. 对同一张参考图独立生成两个污染视图，二者都恢复 X；在重建损失之外加入表示一致性。不同模态的原始像素不直接逐元素对齐为同一个目标。
4. 单模态恢复成立后，增加另一模态作为辅助输入，并把是否同期/源 tile 是否一致作为可审计条件。时间差不能冒充噪声强度。
5. 最后测试未见噪声类型、未见强度，以及 mask 边界误差；区分“已知 mask 的补全”和“不知道污染位置的去噪”。

训练可采用 25% 原始自重建、75% 合成污染恢复作为起始候选。验证与最终评估必须包含零噪声，检查模型是否损伤原本可靠的观测。

## 可复现与存储

训练时在线生成噪声，不复制整套约 222 GiB 的原始数组。保留只读原始参考；可将少量固定案例导出供检查。

随机状态由稳定哈希派生：`dataset_version / split / sample_id / modality / noise_type / severity / realization / base_seed`。不要用进程随机化的 Python 内置 hash。训练额外引入 epoch 或 draw_index；验证固定，不随 epoch 或 DataLoader worker 数变化。

同一验证样本对所有模型使用同一污染 realization。pilot 可固定两次 realization；正式评估可固定三次。重复噪声视图始终继承原样本划分，不拆到不同 split。当前没有独立 test 目录；正式最终测试需事先冻结独立 tile 子集，不能将用于调参的 val 同时当作最终 test。

每次记录原始样本键、模态、噪声类型、强度、seed、期望/实际覆盖率、参考有效数、噪声模型版本和 mask 来源。

## 指标与边界

HLS 以逐波段 RMSE/MAE、光谱角和预定义光谱指数误差为主；LST 在单位确认前报告原始或固定归一化单位的 RMSE/MAE，确认 scale/offset/单位后再报告物理单位误差。两者均分污染区、保留区、全参考区报告，并检查边缘和极值保持。

token agreement、flip rate、code usage 等用于解释量化机制；不以 token 更稳定单独判定恢复成功。相同模型的不同污染视图可以比较 token，独立训练的码本 index 不能直接一一比较。

合成实验建立可控真值，可回答模型对规定退化的恢复能力。真实污染的迁移能力需要单独验证；本协议不把人工加噪结果直接等同于真实去云性能。
