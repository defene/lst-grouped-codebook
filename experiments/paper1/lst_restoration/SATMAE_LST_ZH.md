## 结构

采用 [SatMAE++ 官方仓库](https://github.com/techmn/satmae_pp) `34f46564e4de1e4108fc12dc191fac600d62441c` 的 `models_mae.py` 两尺度版本。保留可见 token 编码、mask token 解码、低尺度图像重建，以及“图像投影到特征—转置卷积上采样—残差卷积—图像输出”模块。没有拿 Prithvi 或普通 ViT 解码头替代其多尺度模块。

该版本从 128×128 重建到 256×256：编码器 patch8，在原始 LST 上覆盖 16×16 像素；共16×16个patch。外部遮盖位置与 Prithvi 的原图 patch16 条件共用，被遮盖 token 在编码器 attention 前删除，不再额外随机遮盖。

输入降采样只使用已提供的污染观测及有效 mask；采用不重叠2×2有效像素加权平均，不跨物理 patch 边界，也不读取目标。颜色组在编码颜色空间内做该平均，不声称它等价于先平均温度再着色。编码器原始信息经过降采样，这与 Prithvi 直接读取256图像有区别；属于架构设计差异，不声称两者输入张量完全相同。

由原生256×256 fine LST 生成低尺度监督，**不额外调用 coarse LST 数据或另一传感器**。单通道温度残差 R 与构造颜色 C 各自从零训练，无时间、多光谱分组或预训练权重。

## 多尺度监督与适配差别

采用低尺度 MSE＋高尺度 L1 的多尺度形式，均在逆映射后的温度残差域、以训练集固定残差标准差 s 归一化，两个系数均为1：

`L = masked_mean(((r128_pred - r128_ref) / s)^2) + masked_mean(abs((r256_pred - r256_ref) / s))`

低尺度参考按2×2真实有效温度加权平均，部分有效区域按有效像素比例计权。patch16训练仅监督人工缺失且参考有效区域，clean训练监督全部参考有效区域；无效位置不进入损失。不做逐patch目标归一化，避免改变温度恢复任务。该模型不额外叠加主线的高尺度MSE、梯度、表示损失，也无KL/VQ损失。

这是 LST 任务的显式适配：[原论文](https://arxiv.org/abs/2403.05419)和官方代码的高尺度L1使用全图，本实验改为参考有效/任务指定区域；温度域尺度、mask与clean控制也不同。不把结果写成原论文完整训练配方复现。与 Prithvi 比较时披露结构、降采样及损失共同变化，不能仅归因于多尺度模块。
