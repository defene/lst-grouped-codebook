# LST 十张结果表：训练顺序与填表协议 v1

2026-09-27。此版本生成独立实验计划、关闭执行的配置和空结果表；没有提交训练。旧 174 配置计划与历史实验保留。本计划专注 LST 图像复原，不包含 HLS、下游任务、连续 AE 或 VAR 多尺度。

## 先确定什么，再训练什么

先建立可审计的共同基线，再开展表示及初始化对照，然后扩展污染、模型、码率，最后做预先指定的种子复验。每个模型最终检查点只训练一次，通过 job_id 复用到多张表。科研执行顺序不等于论文表格顺序。

主线仍按最近讨论采用**给定完整参考均温的 oracle 残差条件**，表格明确标注；可见观测均温和不提供均温分别进入表6。oracle 是额外侧信息假设，不能代表部署时无需均温。直接绝对温度仍必须保留，不能用“绝对温度＋oracle 均温”替代。

共同颜色基准预先固定为线性路径 C，原生单通道为 R；不根据 test 结果挑选“最好颜色”后替换总体表。G、C_power、C_asinh 的作用通过表示消融展示。当前没有选出获胜映射。

**当前共166份可静态验证的配置，均关闭执行、均未完成运行验收。** 每份5个完整epoch，若全部运行，共181,749,250次训练记录呈现；不含待接入组、技术测试、重算成本。无法在未测吞吐前给出可信GPU-hours。不能把166理解为已启动队列，也不能把它理解为最终完整实验总数。

P0通过后，正式第一批仅为P1的16组；实际可先运行其中VQ/FSQ四种R/C×clean/pixel10组合共8组以验证整个产物链，再补LFQ/BSQ。正式模型始终保留完整预算，短程技术检查单独标记，不冒充正式结果。P2中SD应先完成对应零微调评估，再微调；地理源码和其余权重的接入可在P1/P2期间准备。

## 尚需补齐的正式对照，不能用别组代替

1. **不提供每图均温的绝对温度组**：拟VQ/FSQ×R/C×三种训练，共12组。当前数据和模型接口即使field=absolute仍传mean_celsius，先修正侧信息输入、解码接口和码率统计再生成配置。补齐后当前已确定范围为178组。
2. **自然KL-VAE同架构随机初始化**：当前SD/SDXL/FLUX入口强制加载预训练权重。需要实现同架构从零初始化，才能归因“预训练收益”；不能拿另一套小卷积VQ网络当其随机初始化对照。先覆盖SD的表示消融，对其余两种模型覆盖范围单独登记，未落实前不报确定训练数。
3. **自然图像预训练离散模型**：VQ/FSQ/LFQ/BSQ须逐个确认具体公开模型、官方权重、许可及适配。现有四种离散实现均为从零训练。保留官方原生码本和网格做迁移；不能改成1024状态再称官方零微调。该轨道与共同骨干、共同码率的从零训练轨道分表块展示，预训练离散对照不得取消。
4. **报告接口补充**：极端残差阈值须由train预先冻结；图内/图间分解、跨seed汇总和达到阈值的耗时统计尚需接入。当前空表保留null，不把未实现字段填零。

这些缺口登记在manifest的unresolved_cells中。166份静态配置不代表十张表已经具备所有实验单元；自然预训练离散及同架构scratch的数目确定后需发布新计划版本，不覆写本版。

## 为什么按这个顺序

- P1先确立压缩瓶颈和去噪基准，检查原图细节是否已被抹平，避免所有后续比较依赖一个未经验证的参照。
- P2先用VQ/FSQ和SD验证表示作用，隔离单/三通道、线性/非线性和颜色路径的差别。此消融不能泛化声称所有架构都获益；若扩展LFQ/BSQ或SDXL/FLUX非线性组，另立版本。
- P3验证噪声稳健性，同时复用clean/pixel10模型形成完整训练×测试条件交叉；不为每个测试噪声重新训练模型。
- P4加入外部架构。参数或连续/离散载荷无法对齐的组报告真实数值、放在不同表块，不声明已严格等参数或等码率。
- P5/P6/P7是三个独立解释分支，按资源串行或并行；P8固定复验已登记组合，不按test得分决定复验谁。较早阶段出错只修执行问题，不悄悄改变预算/表示/损失。

## 十表如何填充

目录内每张表提供Markdown与JSON模板。每行包含唯一job_id、模型、表示、训练污染、均值条件、seed、配置摘要；数值为空，状态not_run。manifest保存一份训练对应多张表的映射，后续填写result_directory及证据路径。当前没有自动提交器或跨作业自动填表器。

|表|主展示范围|必要口径|
|---|---|---|
|T1 总体结果|共同线性表示、seed17、mixed模型；离散/连续/扩散分块|原生R与RGB条件分块；完整test；raw读出|
|T2 训练污染|clean/pixel10/mixed交叉评估|输入、目标、有效/可见mask摘要相同才可配对|
|T3 表示|VQ、FSQ、SD的明确表示组合|物理温度单位；SD不支持原生单通道R则标不适用；非线性辅助损失含局部Jacobian补偿，不能把整个收益只归因于颜色分布|
|T4 迁移|同架构scratch、零微调、微调分别列出|当前只具备KL加载入口，缺失scratch/预训练离散行必须明确标待补|
|T5 率失真|8/10/12 bit三点、相同网格|每点不同模型需训练；报告实测码流、32bit均温、头部等开销；连续KL无离散困惑度|
|T6 均值|oracle残差、visible残差、无均温absolute|oracle同样给各模型；visible从带噪观测计算；absolute尚待修正|
|S1 审计|全部模型|实测参数、编码/解码成本、数据/权重/预算指纹|
|S2 空间编码|核心离散模型|全局使用率不能替代图内结构；token稳定性不能单独证明抗噪|
|S3 MAE|相同patch16缺失支持|pixel10结果不混入；SatMAE++的两尺度输入/损失差异明示|
|S4 稳定性|固定种子及更强污染|种子波动和tile级配对区间分别报告；不把两个视图当独立样本|

主表RMSE使用汇总有效像素平方误差的开方，不平均batch RMSE；空间误差去除每图预测误差均值，梯度单位°C/pixel。缺失区域为空时记不适用。噪声和云形缺失目前为合成干扰，不能宣称真实传感器标定或真实云消除。

所有正式训练使用HLP v2：train218975、val11684、test11757；5epoch、1,094,875次记录呈现、batch64、17,110次更新。最后完整epoch选模，不使用test调参。每个评估条件完整val/test，各两视图；配置预声明的更强噪声同样评估，不能只展示有利条件。历史test已被查看，不把这次test称为从未接触的盲测集。

训练内核、损失和所有执行源码在P0后冻结。修改需要新版本与新验收，旧预检摘要不复用。幂变换尾部敏感性、超范围输入策略必须在train/技术检查阶段解决，不能到test异常后改映射。

## 结果复用、成本与图像

同一正式配置的权重可支撑多个表，不能因为填另一张表再次训练。不同污染评估只增加评估成本。预训练零微调在相同权重、表示、数据、均值、污染及推理配置下可以复用：本版登记8个候选复用组，但当前运行器没有共享缓存；在实现证据绑定缓存前可能重复评估，不能宣称已经去重。

新增码率需要新训练。相同名义状态数不是相同熵码率；自然预训练模型不强行缩改官方码本。原生与颜色输入、不同骨干需分别做实测参数审计，不能仅按模型名字宣布对齐。

训练作业小时包含验证/存盘/资源竞争；共享GPU作业时间不相加当单卡GPU-hours。单卡成本按有证据的训练区间并集统计，异常会话保留下界与重算，不含停机空档。三组并行不是默认要求，必须先实测显存与速度决定并发。

四组图：同样例横向预测图（clean与受损分开）、温度细节/剖面、率失真与学习曲线、颜色路径/token分布。样例在查看预测前按确定性ID规则选择原始全有效图像，固定色标、放大框和误差范围，不挑某模型赢的样例；图像必须实际查看后才标视觉复核。

## 生成与使用

```powershell
.venv-paper1/Scripts/python.exe -X utf8 -m experiments.paper1.lst_restoration table-plan --output experiments/paper1/lst_tables_v1_20260927_r1
```

命令仅使用标准库，拒绝覆盖非空目录。生成manifest.json、table_registry.json、configs/与tables/；不会加载torch、数据或权重。正式运行仍须经过现有components/data-budget/model预检与对齐审计，显式绑定证据并启用单份配置。静态通过不是正式训练放行。
