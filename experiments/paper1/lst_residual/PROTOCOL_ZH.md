# A04：温度残差预测短程试验

用户授权：2026-09-13 晚间先试温度残差预测，HLS 后续另行设计。

在独立实验入口上扩展现有卷积 VQ-VAE，保持 eo_data、eo_denoise、A02/A03 检查点和数据预处理不变。

| 对照组 | 预测目标 / 输入 | 额外空间损失 λ |
|---|---|---:|
| absolute | 原来的绝对温度表示 | 0 |
| absolute_spatial4 | 原来的绝对温度表示 | 3 |
| residual | 相对可见输入均值的残差 | 0 |
| residual_spatial4 | 相对可见输入均值的残差 | 3 |

残差模型只从 input_mask 为真的输入像素计算均值 b，输入为 image−b、缺失处仍为零并保留掩码，输出为 decoder(tokens)+b。b 是冻结全局标准化空间下的可见均值；物理温度仍按摄氏度×100 协议读取。模型不获取干净目标的均值或方差，也不把真实缺失像素送入输入。全缺失输入明确拒绝，不伪造温度基准。

目标函数为既有重建 MSE + λ×去均值空间 MSE + 0.1×梯度损失 + 既有 VQ 损失。λ=3 相当于空间部分的总权重为4；均值误差权重仍为1。残差预测与去均值损失是独立的两个因素。

四组固定：种子17、随机初始化，不加载旧模型；同样的10%已知掩码缺失训练输入、同样样本流；1024码字，10个残差尺度、680索引、32维码字，最细16×16，256×256输入。残差组额外需要一个FP32均值，共6832bit/图，相对6800bit基线多32bit，码率不含共同掩码/头部/模型。

先4组各8步、64条训练/16条验证的技术检查，验证梯度有限、保存/读取/双条件评估、样本顺序和显存。通过后自动4组各2000步，微批4、累积16，有效batch64，训练池全量230659条、呈现128000条/组；验证256条、干净/10%缺失两条件各2次实现。学习率1e−4，warmup100步，cosine至1e−5，AdamW其余参数沿用A03。500步定期验证，250步存盘，最终比较固定last.pt。短程试验不自动扩大为10813步全量训练。

两个GPU作业并行，每作业分配上限12GiB；全局可用显存低于2GiB时请求存盘并停止。根目录STOP标记可停止整个实验。使用独立输出 runs/paper1/lst_residual_20260913；失败不启动重复队列。统计函数、残差加回、输入平移等变、无效像素排除和辅助码率已有单元测试。

训练后自动生成中文报告、相同8条预选记录的4组配对温度图；报告总误差、图像均值误差、空间误差、梯度误差、缺失区/保留区误差、码本使用和时间/显存。监测任务负责检查图像和解释结果，并在完成/失败时通知用户。HLS不训练。并行作业墙钟时间单列，不直接相加冒充独占GPU-hours。
